Enter your Sleeper username to automatically load every league you're in, your rosters, and a full diagnostic — built to manage 10+ teams from one screen.

Sell-high / buy-low / Trade Lab / Waiver Wire calls are built from live Sleeper data (roster, internal search rank, injury status, 48h community add/drop trends, and real league transactions) as a proxy for market "hype" and value. Dynasty Rank and Dynasty Trade Value are pulled automatically and for free from DynastyProcess.com, an open-data project (GPL-3.0 licensed, sleeper_id-matched) that aggregates FantasyPros' dynasty consensus rankings into a public dataset — no login or API key involved. Weekly point Projections come from Sleeper's own projections feed — note that, unlike every other endpoint this app uses, that one is not part of Sleeper's documented public API; it is the internal endpoint their own apps use, relied on by the open-source Sleeper developer community, and it can change or go away without notice (the app falls back to "Unavailable" cleanly if that happens, rather than breaking). This app still cannot pull live data from FantasyPros, Draft Sharks, or Footballguys directly — none of them expose a public API for their own rankings/trade-value charts — and there's no equivalent free open dataset yet for weekly/ROS expert rankings, so the Notes field on the Full Roster tab stays manual: type in what you find via the reference links, and it's saved locally in your browser. Lineups cannot be edited from this app: Sleeper's own API is documented as read-only, with no endpoint for setting starters, so no third-party tool can submit a lineup change on your behalf. The Lineup Check on the This Week tab is a read-only sanity check, and the "Edit Lineup in Sleeper" button opens the exact league on Sleeper's site so the actual change is one click away.
